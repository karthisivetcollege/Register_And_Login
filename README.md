# Flask User Authentication System

A simple and clean **Flask web application** that implements user authentication features such as user registration, login, logout, and protected pages.

## 🚀 Features

- User Registration
- User Login
- User Logout
- Home Page
- Login/Logout State Handling
- HTML Templates using Jinja2
- Flask-based backend
- Simple and lightweight project structure

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Jinja2
- Git & GitHub
